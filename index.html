Thiết lập MCP đơn giản hơn

Trang này là trung tâm hướng dẫn của AI Film Studio. Nó không phải MCP server: GitHub Pages không chạy backend và không truy cập vào dữ liệu máy tính của bạn.

✓ Giữ nguyên ba Chrome Workspace · ✓ Không cần Claude API key · ✓ MCP chỉ truy cập dự án được bạn cho phép

1. Mở AI Film Studio

Cài bản có nút Bật MCP + HTTPS (thử nghiệm) tại Sản xuất → Web Instant → MCP. Chọn Project đang làm việc.

Nếu chưa có cloudflared, chạy winget install --id Cloudflare.cloudflared -e trên Windows.

2. Tạo HTTPS endpoint

Bấm nút Bật MCP + HTTPS (thử nghiệm). Chương trình sẽ tạo URL HTTPS tạm thời và khởi động MCP server trên máy.

Chỉ sử dụng URL thực tế ứng dụng hiển thị, ví dụ https://...trycloudflare.com/mcp.

3. Kết nối Claude Web

Mở Claude Web → Customize → Connectors → Add custom connector. Nhập Public URL mà AI Film Studio hiển thị. Trong phần Request headers, đặt header Authorization với giá trị Bearer <token> (mã lấy bằng nút Copy Authorization trong AI Film Studio).

Bảo mật: Tuyệt đối không dán token vào GitHub Pages, mã nguồn công khai, ô chat hay form dưới đây. Form chỉ xử lý URL trong trình duyệt của bạn và không gửi dữ liệu đi đâu.

4. Kiểm tra

Trong Claude, thử yêu cầu: “Hãy gọi get_status từ AI Film Studio và tóm tắt dự án.” Chỉ khi Claude thực sự nhận được kết quả từ tool thì connector mới được coi là hoạt động.

Vận hành ổn định

Cloudflare Quick Tunnel chỉ phục vụ thử nghiệm; URL sẽ đổi khi khởi động lại. Để có hostname ổn định cần backend HTTPS hoặc Cloudflare Tunnel cố định với tên miền do bạn kiểm soát.

Tài liệu: Claude Custom Connectors · Cloudflare Quick Tunnels

Không lưu mật khẩu, không lưu token, không yêu cầu OAuth trên website này. Không thể thay địa chỉ này cho endpoint MCP.
